
# CodePilot

An AI-powered coding assistant designed to
understand, search, explain, and modify code
repositories using LLMs, retrieval, code
intelligence, and agentic workflows.

## Tech Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- AI: LLM API, structured outputs, tool calling
- Retrieval: Embeddings, vector database, hybrid search
- Code Intelligence: Python AST, Tree-sitter
- Agent: State-based workflow
- Protocol: MCP
- Infrastructure: PostgreSQL, Docker, GitHub Actions
